# Steph Ango's Obsidian System — Full Reference

Source: https://stephango.com/vault

## Philosophy: File Over App

_File over app_ is a philosophy: if you want to create digital artifacts that last, they must be files you can control, in formats that are easy to retrieve and read.

> If you want your writing to still be readable on a computer from the 2060s or 2160s, it's important that your notes can be read on a computer from the 1960s.

## Personal Rules

- Avoid splitting content into multiple vaults
- Avoid folders for organization
- Avoid non-standard Markdown
- Always pluralize categories and tags
- Use internal links profusely
- Use YYYY-MM-DD dates everywhere
- Use the 7-point scale for ratings
- Keep a single to-do list per week

## Vault Structure

- **Root** — personal notes (journal, essays, evergreen notes)
- **References/** — external things (books, movies, places, people)
- **Clippings/** — saved content by others
- **Attachments/** — media files
- **Daily/** — daily notes (YYYY-MM-DD.md), exist only to be linked to
- **Templates/** — note templates

## Navigation

- Rarely use file explorer
- Navigate via quick switcher, backlinks, links within notes
- Use `categories` property + Bases for overview

## Links

Use internal links profusely. Always link first mention of something. Unresolved links are breadcrumbs for future connections.

Example journal entry:
```
I went to see the movie [[Perfect Days]] with [[Aisha]] at [[Vidiots]] and had Filipino food at [[Little Ongpin]]. I loved this quote: [[Next time is next time, now is now]].
```

## Fractal Journaling

1. Daily: unique note hotkey (YYYY-MM-DD HHmm)
2. Every few days: compile salient thoughts
3. Monthly: review compilations
4. Yearly: review monthly reviews (40 Questions template)
5. Random revisit: periodically travel randomly through vault

> Don't delegate understanding.

## Properties

Every note starts from a template with properties:
- Dates: created, start, end, published
- People: author, director, cast, guests
- Themes: genre, type, topic
- Locations: loc, city, coordinates
- Rating: 1-7 scale

Rules:
- Reusable across categories
- Composable templates
- Short names (start, not start-date)
- Default to list type

## Rating System (1-7)

7=Perfect, 6=Excellent, 5=Good, 4=Passable, 3=Bad, 2=Atrocious, 1=Evil

## To-Dos

- One weekly note with to-dos
- Write from scratch without looking at previous week
- If you can't remember it, it wasn't important
- Roll over or drop unfinished items

## Evergreen Notes

- Title distills idea into a sentence
- Turn ideas into objects you can manipulate
- Don't need to agree with the idea
- Can be very short
